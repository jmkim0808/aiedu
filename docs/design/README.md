# 설계문서

이 폴더는 비어 있다.

`srlee0808project/powernet` 에 있는 설계문서를 여기로 옮겨온 뒤 개발을 시작한다.
문서가 저장소 안에 있어야 구현과 설계가 같이 버전 관리되고, 나중에 "왜 이렇게
만들었는지"를 커밋 이력에서 되짚을 수 있다.

## 옮기는 방법

1. 원본 저장소에서 문서 파일을 내려받는다.
2. 이 폴더에 넣고 커밋한다.
3. 문서를 읽고 `db/migrations/` 와 `src/` 에 구현을 시작한다.

## 옮긴 뒤 정리할 것

| 항목 | 어디에 반영 |
|---|---|
| 권한·역할 정의 | `.dev.vars.example` 의 ROLE_MAP 역할코드, `src/api.js` 의 권한 검사 |
| 데이터 모델 | `db/migrations/0001_*.sql` |
| 화면 구성 | `public/` |
| 외부 연동 | `wrangler.toml` 바인딩 (R2 · 시크릿) |
